Прогрессиялар

Сандар тізбегінің заңдылығын анықта. Негізгі формулаларды қарап, мысалдарды талда да, соңындағы түсіндірмелі тест арқылы біліміңді тексер.

Арифметикалық прогрессия

Көршілес екі мүшесінің айырмасы тұрақты болатын тізбек арифметикалық прогрессия деп аталады.

aₙ = a₁ + (n − 1)d

d = aₙ₊₁ − aₙ — айырымы.

Мысал: 5, 8, 11, 14, …
d = 3, сондықтан a₁₀ = 5 + 9·3 = 32.
Sₙ = n(a₁ + aₙ) / 2

Геометриялық прогрессия

Әр мүшесі алдыңғы мүшені тұрақты санға көбейту арқылы алынатын тізбек геометриялық прогрессия деп аталады.

bₙ = b₁ · qⁿ⁻¹

q = bₙ₊₁ / bₙ — еселігі (бөлім нөл болмауы керек).

Мысал: 3, 6, 12, 24, …
q = 2, сондықтан b₆ = 3·2⁵ = 96.
Sₙ = b₁(qⁿ − 1) / (q − 1), q ≠ 1

Біліміңді тексер

Әр жауапты таңда да, «Жауаптарды тексеру» батырмасын бас.

1. 3, 7, 11, 15, … тізбегінің айырымы қандай?

2. a₁ = 2, d = 5 болса, a₆ неге тең?

3. 2, 6, 18, 54, … тізбегінің еселігі қандай?

4. b₁ = 4, q = −2 болса, b₅ неге тең?

5. a₁ = 2, a₄ = 14. Алғашқы төрт мүшенің қосындысы?

6. 1, 4, 16, 64, … тізбегі қандай прогрессия?
